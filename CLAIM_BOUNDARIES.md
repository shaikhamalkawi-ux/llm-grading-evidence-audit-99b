# Evidence/claim boundaries (R106)

1. This is a **purposive**, retrospectively selected report-level panel: 19 sources, not 19 independently recruited university cohorts, not a representative bibliographic census, not independently human screened. The 496 secondary technical keys had AI-only original title/abstract readings; this does not constitute full-text human PRISMA selection.
2. The fixed G0–G6 states are source-specific observational availability labels: `O` observed scoped result, `P` partial/proxy, `NR` not reported, `NA` inapplicable, `U` unverified. They are **not weights, quality grades, thresholds or trust scores**. The source tables were not independently double-coded by human annotators.
3. The endpoint-event overlay uses the **same 19 report IDs**. The four original G3 `O` cases split into three retrospective reported grade comparisons (SG05/07/14) and one actual LLM-assigned course marking workflow (SG18). This does **not** imply that all four report correct formally awarded grades.
4. Six original G6 `P` cases have different endpoints: SG02 flags, SG03 simulated human substitution, SG04 reference-dependent trigger, SG09 actual appeal-linked mark revision, SG17 and SG18 review requests. **No independent validated corrected official LLM-issued grade** is established from these six sources; absence in this panel is not absence in the field.
5. EvalHack published Table 12 provides four cells `125,205,218,452`. The 78.2% is the **conditional upper bound** if all 125 flagged out-of-tolerance answers were successfully corrected, no previously valid flag was harmed and unflagged answers were untouched. It is **not observed performance**.
6. Kerwat reference supports only `70 Merit / 44 Distinction` among 114 essays; a constant-Merit exact agreement `70/114` and 100% within-one-band show restricted reference support. No claim the constant predictor is a valid scoring system or statistically superior model.
7. Saez et al. (2026) already present a seven-part university LLM grading framework. The comparison here is a **crosswalk of purposes**, not an instrument head-to-head test, not independent efficacy validation. See DOI `10.1038/s41598-026-48656-3` for its original scope.
8. No independent human eligibility or annotation reproducibility, raw student answers, private provider-hit archives, teacher-grade decision logs, independent corrected-award adjudication, causal effects, or verified formal transcript amendments are included.
9. Public GitHub visibility is verified separately from an immutable archived DOI. Author/coauthor-approved code/data licences, final declaration metadata and independent screening remain pending.

A human reviewer template exists at `human_review/` but has **not been executed**. It contributes no observed human validation or kappa.
